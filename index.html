How to dive

Each round has 7 prompts. Type one valid answer before the timer runs out.

Built-in rarity scores estimate how uncommon an answer is. Obvious answers earn fewer points; obscure valid answers earn more. Rarity is estimated from this built-in dataset, not live global player data.

Duplicate answers within a dive earn 0 points. Each point adds 10 meters. Daily Dive uses one locked 20-second timer.
